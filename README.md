# CheddaTech 🧀

**Game infrastructure for indie devs.** Home of [CheddaBoards](https://cheddaboards.com): online leaderboards, achievements and player accounts you can drop into your game in minutes. Free to use, no per-player fees, and the backend is open source.

### 🎮 Pick your engine

| Engine | Get it | What it is |
|---|---|---|
| **Godot 4** | [cheddaboards-godot-addon](https://github.com/cheddatech/cheddaboards-godot-addon) · [Asset Store](https://store.godotengine.org/asset/cheddatech/cheddaboards) | The addon. Enable the plugin, add your API key, submit scores. |
| **Godot 4 (full project)** | [cheddaboards-godot](https://github.com/cheddatech/cheddaboards-godot) | Starter template with menus, leaderboards and login built in. Clone it and make your game. |
| **Godot 3.6** | [cheddaboards-godot3-addon](https://github.com/cheddatech/cheddaboards-godot3-addon) | Community-supported backport. |
| **Unity** | [cheddaboards-unity](https://github.com/cheddatech/cheddaboards-unity) | C# SDK with the same feature set. |
| **Anything else** | [REST API docs](https://docs.cheddaboards.com) | Plain HTTP, so it works from any language or engine. |

Games using CheddaBoards ship on Google Play, iOS, itch.io, Windows and the web.

New to it? [**cheddaboards-dodge-the-creeps**](https://github.com/cheddatech/cheddaboards-dodge-the-creeps) adds an online leaderboard to the classic Godot demo, and the four-commit history is the tutorial.

---

### ✨ What you get

- **Leaderboards** with all-time, weekly and daily boards out of the box, plus your own category boards
- **Achievements** synced server-side, so progress survives a cleared browser or a new device
- **Player accounts** that start anonymous and can link to Google or Apple later without losing anything
- **Anti-cheat** options you choose per game (play sessions, score caps, time validation)
- **Moderation** from the dashboard: remove entries or wipe a player, with an audit log

### 🧱 Under the hood

The backend is a single open-source canister on the Internet Computer, sitting behind a hardened API proxy. Use the hosted service at [cheddaboards.com](https://cheddaboards.com), or [run your own](https://github.com/cheddatech/cheddaboards).
